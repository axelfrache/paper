Flat diagram icons used by Paper.

Source:
- Lucide icons: https://github.com/lucide-icons/lucide

The SVG filenames are normalized to match the internal diagram icon IDs. The same visual language is used for product logos, cloud resources, and Kubernetes resources so flat diagrams stay readable in light and dark themes.

Keep the diagram data model storing icon IDs only; do not inline SVG payloads into notes.
